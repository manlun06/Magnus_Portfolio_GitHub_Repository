# Magnus Lund-Andersen — Portfolio

**Live portfolio:** https://manlun06.imkatta.no/Portfolio/

Dette repositoryet inneholder HTML-, CSS- og prosjektfilene for portfolioen min. Nettsiden presenterer arbeid innen webutvikling, spillutvikling, praktisk IT og medieproduksjon.

## Innhold

- `index.html` — landingsside
- `projects.html` og `projects/` — prosjekter og prosjektdokumentasjon
- `about.html` — om meg
- `skills.html` — ferdigheter
- `cv.html` — CV
- `application.html` — søknadsmal
- `contact.html` — kontakt
- `assets/` — stilark og grafiske ressurser
- `windows10-dokumentasjon.docx` — dokumentasjon fra Windows-prosjektet

## Teknologi

HTML5 · CSS3 · JavaScript (der det brukes)

## Kjør lokalt

1. Last ned eller klon repositoryet.
2. Åpne `index.html` i nettleseren.
3. Ingen byggesteg eller pakkeinstallasjon er nødvendig.

## Publisering med GitHub Pages

1. Opprett et nytt repository på GitHub.
2. Last opp innholdet i denne mappen direkte til repositoryets rot (slik at `index.html` ligger øverst).
3. Gå til **Settings → Pages**.
4. Velg **Deploy from a branch**, branch `main` og folder `/ (root)`.
5. Lagre. GitHub viser adressen til den publiserte siden.

Den offisielle portfolioen ligger fortsatt på KattaHotell: https://manlun06.imkatta.no/Portfolio/

## Før CV og søknad sendes

Fyll inn og kontroller kontaktinformasjon, telefonnummer, sted og eventuelle datoer/erfaringer i CV-en og søknaden. Tilpass søknadsteksten til den konkrete bedriften og stillingen. Ikke publiser private kontaktopplysninger i et offentlig repository dersom du ikke ønsker det.

## Merknad om kildekoden

Denne pakken er bygget fra den siste portfolio-kildepakken som var tilgjengelig i arbeidsmappen. Den inneholder en selvstendig HTML-utgave. Kontroller at den samsvarer med den versjonen som er publisert på KattaHotell før du bruker repositoryet som en fullstendig kopi av live-nettsiden.
