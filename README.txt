MAGNUS — PORTFOLIO

Live nettside: https://manlun06.imkatta.no/Portfolio/

Dette er en statisk HTML/CSS-pakke. Åpne index.html lokalt, eller last opp alle filene til et webhotell med index.html i rotmappen.

GitHub: Opprett et repository og last opp innholdet i denne mappen direkte til roten. Aktiver deretter GitHub Pages under Settings -> Pages -> Deploy from a branch -> main -> /(root).

CV: cv.html
Søknad: application.html
Prosjekter: projects.html og mappen projects/

Fyll inn og kontroller kontaktopplysninger og felter i klammer før CV eller søknad sendes.

Merk: Denne pakken er en selvstendig HTML-utgave basert på den sist tilgjengelige kildepakken. Kontroller at den samsvarer med den publiserte nettsiden før du bruker den som fullstendig kildekodekopi.
